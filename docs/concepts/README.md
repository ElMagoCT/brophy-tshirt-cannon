# Mark 5 concepts

20 rough concept renders (single, double, triple, revolving) in a small Three.js
editor: click a design to orbit it and tune body, mount, barrels, accents and LED
colour; edits persist in your browser. LEDs are painted on as flat emissive
textures (no lights, no bloom) so it stays light.

- Open: `python3 -m http.server 8791` in this folder, then http://127.0.0.1:8791
- Still renders: `renders/01-sabre.jpg` … `renders/20-cyclone.jpg`, plus `renders/contact-sheet.jpg`

Concepts only: proportions are plausible (6" mecanum, 3" OD barrels, 2" steel
chambers behind 1" QEVs), not engineered.
