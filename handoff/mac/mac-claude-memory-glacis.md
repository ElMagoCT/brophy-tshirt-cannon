**How to apply:**
- To update the import:
  1. Edit `cad/glacis` and run `robot.py`.
  2. Snapshot the Onshape document as a version if its state has none ([[onshape-version-after-edits]]).
  3. Upload only the changed STEPs.
  4. Insert each new Part Studio (`isWholePartStudio`) into its system's sub-assembly (POST /api/v6/assemblies/d/w with {name} makes one; insert it in the main assembly with `isAssembly`), delete the old instances by nodeid, then delete each old Part Studio together with its BLOB. Translate with flattenAssemblies=true. Instance ids with "+" return 500 on DELETE but may be gone anyway: re-read.
  5. Create a named version after.
- Count each Part Studio's parts against its assembly instances after a swap. Sheet bodies aren't instanced: tangent or zero-web cuts in the STEP come in as sheets. That happened to the wheel plates' lightening holes in C.2.
- Long swap scripts time out the Chrome tool but keep running in the page; re-check the state with a short read.
- Rename a tab: POST /api/v6/metadata/d/{did}/w/{wid}/e/{eid} with properties [{propertyId 57f3fb8efa3416c06701d60d, value}] (POST /elements/... returns 405). Upload a STEP by injecting an <input type=file> into a cad.onshape.com help page, file_upload to it, then fetch with the XSRF-TOKEN cookie as X-XSRF-TOKEN; kick swaps off without awaiting and poll a window variable.
- Run fetches from `https://cad.onshape.com/api/v6/users/sessioninfo`, not the document page. A browser batch carries at most 10 MB of file_upload, so send one big STEP per batch.
- Sheets: unmerge A4:J200 FIRST (values written into a merged cell's hidden part are dropped), then write the rows, then redo the section merges, the green fill and the B/C/H validations. Check B2 against the script's total.
- Onshape API calls: run them from a cad.onshape.com help page (sessioninfo opens as a chrome:// JSON view where JS is blocked); sessioninfo 204 = signed out.
- Before committing, check `git status` for another session's work; stage by path.
