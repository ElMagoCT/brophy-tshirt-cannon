# firmware/

PlatformIO project for the ESP32-S3: WiFi AP, WebSocket server, dashboard served
from flash, ADS1115 pressure reads, LEDC PWM drive outputs, fire state machine
(meter → hold → arm → fire → vent) and a software pressure cap. Boot target < 3 s.
