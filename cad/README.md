# cad/

Parametric printable parts (CadQuery or OpenSCAD) with STL exports in `stl/`.
Main CAD lives in Micah's Onshape; this folder is for parts generated from code.

Rule: nothing printed on the pressure boundary (tank, chambers, valves, fittings).
Print material for outdoor Arizona use: PETG / ASA / PETG-CF / PA-CF for structure,
TPU for rollers, bumpers and vibration isolators. No PLA on the robot.
